# Дела и дни

Одностраничный сайт: список дел с напоминаниями, подробная статистика и счётчик
оставшихся дней до 80 лет. Один файл `index.html` — ни сборки, ни зависимостей,
ни сервера. Открывается двойным щелчком или раздаётся любым статик-хостингом
(GitHub Pages подхватит из корня как есть).

## Что умеет

**Дела**
- Заголовок, заметка, срок с точностью до минуты, важность, список-тег.
- Повторы: каждый день, неделю, месяц, год. Закрыл — следующая копия появилась сама.
- Фильтры «сегодня / просрочено / все открытые / без срока / выполнено»,
  фильтр по спискам, поиск, четыре сортировки.
- Правка и удаление на месте, `Ctrl + Enter` — добавить.

**Напоминания**
- Системные уведомления браузера: заранее (настраивается общим правилом и
  отдельно для дела) и в момент срока.
- Ежедневная сводка в заданное время: сколько открыто, что просрочено,
  ближайшие пять дел и сколько дней осталось.
- Настойчивый режим — повтор каждые 15 минут, пока просроченное не закрыто.
- Всё, что просрочилось, пока вкладка была закрыта, не сыплется пачкой:
  при открытии показывается одна общая строка.
- Уведомления приходят, пока вкладка открыта — браузер иначе не умеет.
  Закреплённая вкладка решает вопрос. Число в заголовке вкладки показывает,
  сколько дел горит.

**Статистика**
- Десять показателей: всего, выполнено, в работе, просрочено, серия дней подряд
  и её рекорд, закрыто сегодня и за неделю, средний темп, среднее время от
  заведения до закрытия, доля сделанного вовремя.
- График за 30 дней: заведено против закрытого, с наведением и таблицей.
- Разрез по дням недели и по часам суток — видно личный ритм.
- Разрез по спискам: сколько закрыто, сколько ещё висит.
- Связка с возрастом: при нынешнем темпе — сколько дел впереди до горизонта.

**Счётчик жизни**
- Вписываешь возраст (или точную дату рождения) — сайт считает, сколько дней
  осталось до 80 лет, и пишет это строкой «до смерти ≈ N дней». Число
  пересчитывается каждый день, в том числе при смене суток на открытой вкладке.
- Горизонт настраивается: не обязательно 80.
- Возраст, прожитые дни, недели впереди, оставшиеся дни рождения, дата отсечки.
- Сетка недель: 80 строк по 52 клетки, прожитое залито, текущая неделя красная.

## Данные

Всё лежит в `localStorage` этого браузера. Наружу ничего не уходит.
В настройках есть выгрузка в JSON и загрузка обратно — для переезда между
браузерами. Опубликованная копия дополнительно синхронизируется через
хранилище артефакта, если оно доступно; локально этот код просто не включается.

## Разработка

Зависимостей нет. Правится `index.html`, проверяется открытием в браузере.
Внутри: токены темы в `:root` (светлая, тёмная по системной настройке и по
переключателю), графики рисуются в SVG, сетка недель — в канвасе по цветам
текущей темы.
