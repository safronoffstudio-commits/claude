# Дистанции — телеграм-бот с мемами

Бот меряет расстояния. Настоящие — до Луны, до Владивостока, до дна Марианской
впадины. И те, что человечеству не даются: от кровати до холодильника.
Вторые стабильно оказываются длиннее.

Картинки генерируются на лету (satori + resvg внутри `@vercel/og`), без внешних
сервисов и без базы данных.

## Что умеет

| Команда | Что делает |
|---|---|
| `/meme` | случайный мем |
| `/top` | топ-5 непреодолимых дистанций |
| `/spravka` | именная справка о преодолении |
| `/help` | список команд |
| любой текст | «до зарплаты» → персональный мем |
| `@бот ...` | inline-режим, работает в любом чате |

Шесть визуальных шаблонов: `ladder`, `scale`, `versus`, `convert`, `top`, `cert`.
Под каждым мемом кнопка «Ещё дистанцию».

## Деплой

```bash
bash scripts/deploy.sh
```

Скрипт спросит токен, сам сгенерирует `WEBHOOK_SECRET`, зальёт проект на Vercel,
запишет переменные окружения и пропишет вебхук.

Если хочется руками:

```bash
npx vercel link
npx vercel env add TELEGRAM_BOT_TOKEN production
npx vercel env add WEBHOOK_SECRET production     # openssl rand -hex 32
npx vercel deploy --prod
curl "https://<твой-домен>/api/setup?key=<WEBHOOK_SECRET>"
```

Inline-режим включается отдельно у [@BotFather](https://t.me/BotFather): `/setinline`.

## Переменные окружения

| Имя | Обязательна | Зачем |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | токен от @BotFather |
| `WEBHOOK_SECRET` | да | Telegram присылает его в заголовке `X-Telegram-Bot-Api-Secret-Token`; им же защищён `/api/setup` |
| `PUBLIC_URL` | нет | если задан, картинки ссылаются на него; иначе домен берётся из заголовков запроса |

Токен в репозиторий не коммитится — только в переменные окружения Vercel.

## Как устроено

```
api/telegram.js   вебхук: команды, текст, кнопки, inline
api/og.js         рендер картинки (edge-рантайм)
api/setup.js      разовая настройка вебхука и меню команд
api/me.js         getMe для лендинга
lib/memes.js      генератор: 6 шаблонов
lib/data.js       дистанции — реальные и непреодолимые
lib/render.js     вёрстка картинки под satori
lib/rng.js        ГПСЧ с сидом
assets/fonts/     Tektur + JetBrains Mono, урезаны до кириллицы (124 КБ)
```

Ключевая идея: генератор **детерминирован по сиду**. Вебхук не рисует картинку,
а отдаёт Telegram ссылку `/api/og?s=<сид>`, и Telegram забирает изображение сам.
Тот же сид → тот же мем, поэтому картинку можно кэшировать вечно, а вебхук
отвечает мгновенно. Если Telegram по какой-то причине не смог забрать картинку,
бот присылает текстовую версию мема — молчать он не должен.

Цифры настоящие: Эверест 8 849 м, Транссиб 9 289 км, Вояджер-1 около 25 млрд км,
Марианская впадина 10 994 м. На этом держится половина шутки.

## Разработка

```bash
npm install
npm run preview   # PNG всех шаблонов в test/out/
node test/flow.mjs # тесты: детерминированность, шаблоны, грязный ввод
npx vercel dev     # локальный сервер
```

`npm run preview` рендерит теми же версиями satori (0.33.3) и resvg-wasm (2.4.1),
что зашиты внутрь `@vercel/og`, — то есть тем же движком, что и в проде.

## Шрифты

Tektur и JetBrains Mono, оба под OFL. Урезаны до кириллицы, латиницы, цифр и
нужной пунктуации: 124 КБ на три начертания вместо 298 КБ. Цифры везде рисуются
JetBrains Mono — у Tektur «4» слишком похожа на «Ч».
