# Hookcut

SaaS, который превращает расшифровку длинного видео (подкаст, эфир, вебинар, интервью) в готовые сценарии Reels / TikTok / Shorts на 40–60 секунд — по методике из [`reels-framework.md`](./reels-framework.md):

- разбор исходника: таблица сильных моментов (факт / инсайт / конфликт / цифра / эмоция);
- 1–5 сценариев за раз: хук 0–3 с → обещание → 2–3 блока тела → payoff → один CTA;
- голос, текст на экран, кадр и **тайм-код исходника** для каждого блока — монтажёр режет без пересмотра;
- 2 альтернативных хука для A/B, текст обложки, подпись, хэштеги, пометки для монтажа, луп;
- автопроверка по чек-листу (хронометраж, длина хука, один CTA, структура тела);
- экспорт в Markdown, публичная ссылка для клиента (white-label на тарифе Agency);
- интерфейс на русском и английском, сценарии — на 10 языках.

## Быстрый старт

```bash
npm install
npm run dev          # http://localhost:3000
```

Без ключей всё работает: генерации идут через демо-генератор (помечены в интерфейсе), оплата выключена, письма печатаются в лог. Админка — `/admin` для адресов из `ADMIN_EMAILS`.

```bash
npm test             # 41 тест: парсер, ИИ-валидация, Stripe-вебхуки, полный сценарий пользователя
npm run typecheck
npm run build && npm start
```

## Запуск в прод

1. **Claude.** Ключ из [console.anthropic.com](https://console.anthropic.com) → `ANTHROPIC_API_KEY`. Модель по умолчанию — `claude-opus-5-5`, `AI_EFFORT=high`.
2. **Stripe.**
   - Создайте 3 продукта с ежемесячными ценами: Creator $29, Pro $79, Agency $199 → `STRIPE_PRICE_CREATOR/PRO/AGENCY`.
   - Webhook на `https://<домен>/stripe/webhook` с событиями `checkout.session.completed`, `customer.subscription.created`, `customer.subscription.updated`, `customer.subscription.deleted`, `customer.subscription.paused`, `customer.subscription.resumed` → `STRIPE_WEBHOOK_SECRET`.
   - В Customer Portal включите отмену подписки и смену тарифа (между этими тремя ценами) — через него подписчики меняют план.
3. **Почта** для сброса пароля: [Resend](https://resend.com) → `RESEND_API_KEY`, `EMAIL_FROM` с подтверждённого домена.
4. **Деплой.** Один Node-процесс + SQLite на постоянном диске. Все переменные — в [`.env.example`](./.env.example).

```bash
docker build -t hookcut .
docker run -d -p 3000:3000 -v hookcut-data:/data --env-file .env hookcut
```

На Railway / Render / Fly: деплой из Dockerfile, подключите volume в `/data`, задайте переменные, `TRUST_PROXY=1`. Health check — `GET /healthz`.

## Как устроено

| Где | Что |
|---|---|
| `src/ai/prompt.ts` | системный промпт = методика из `reels-framework.md` (кэшируется между всеми пользователями) |
| `src/ai/claude.ts` | вызов Claude: стриминг, structured outputs по JSON-схеме, `fallbacks: "default"` на случай отказа модели, ретраи |
| `src/ai/schema.ts` | схема ответа (моменты, цитаты, ролики, блоки) |
| `src/ai/mock.ts` | демо-генератор без API |
| `src/transcript.ts` | SRT / VTT (вкл. автосубтитры YouTube) / Whisper / «0:00 текст» / обычный текст → `[m:ss] текст` |
| `src/lints.ts` | детерминированный чек-лист по сценарию |
| `src/jobs.ts` | очередь генераций в процессе; незавершённые подхватываются после рестарта |
| `src/billing.ts` | Stripe Checkout, Customer Portal, вебхуки (идемпотентно, состояние берётся из API) |
| `src/usage.ts`, `src/plans.ts` | тарифы и лимиты; неудачные генерации не списываются |
| `src/auth.ts` | email + пароль (scrypt), сессии в БД, сброс пароля |
| `src/app.tsx`, `src/views/` | маршруты и страницы (Hono + JSX, без фронтенд-сборки) |

Безопасность: CSRF-проверка Origin на всех формах, CSP, HttpOnly-сессии (в БД хранится только хеш токена), лимиты на вход/регистрацию/генерации, приватность результатов между пользователями.

## Экономика

Себестоимость генерации на `claude-opus-5-5` ($4 / $20 за 1M токенов): час речи ≈ 20–30 тыс. входных токенов, ответ с размышлением ≈ 6–15 тыс. выходных → **≈ $0,2–0,4**. Фактические расходы и маржа за 30 дней — в `/admin`.

| Тариф | Цена | Генераций | Себестоимость при 100 % использования |
|---|---|---|---|
| Free | $0 | 3 | ≈ $1 |
| Creator | $29 | 40 | ≈ $8–16 |
| Pro | $79 | 150 | ≈ $30–60 |
| Agency | $199 | 400 | ≈ $80–160 |

1 генерация = видео до ~1 часа; более длинные записи списываются по генерации за каждый начатый час, поэтому длинные расшифровки не съедают маржу. Обычно используют 30–50 % лимита. Рычаги: `AI_EFFORT` (стоимость ↔ качество), цены и лимиты в `src/plans.ts`.

$1 000 000 MRR ≈ 8 000 × Creator + 6 000 × Pro + 1 500 × Agency (≈ 15 500 платящих клиентов).
