# Вацок-генератор

Сайт, который генерирует мемы про дагестанское гостеприимство, хинкал, борьбу,
родню и серпантины. Картинка рисуется прямо в браузере на `<canvas>` —
ни сервера, ни базы, ни внешних запросов, кроме двух шрифтов.

Юмор — «про своих»: то, над чем смеются сами. Ничего обидного.

## Как устроено

```
head.part.html    <title>, шрифты, стили
body.part.html    разметка
memes.part.js     33 мема: правила, уровни, диалоги, справки
script.part.js    отрисовка на canvas + логика страницы
build.mjs         собирает части в две версии
preview.mjs       просмотр в Chromium, PNG шаблонов в out/
smoke.mjs         быстрая проверка собранной страницы
```

`build.mjs` делает два файла:

- `index.art.html` — для публикации артефактом (каркас добавляет паблишер);
- `index.html` — самостоятельная страница, кладётся на любой статик-хостинг
  как есть.

```bash
node build.mjs     # пересобрать после правок в *.part.*
node preview.mjs   # посмотреть, что вышло
node smoke.mjs     # проверить index.html
```

## Картинка

Квадрат 1080×1080. Рамка — ковровый орнамент: ступенчатые ромбы с крючками,
рисуются кодом, а не картинкой. Палитра взята у табасаранских ковров:
марена `#A8322A`, шафран `#E0A32E`, индиго `#2E4A6B`, неокрашенная шерсть
`#EFE6D4` на тёмном индиго `#1E1A2E`.

Шрифты: Oswald для заголовков, PT Sans для текста — оба с хорошей кириллицей.

Четыре шаблона: `rules` (нумерованные правила), `levels` (уровни со шкалой),
`dialog` (реплики в два голоса), `cert` (справка с именем из поля ввода).
Формулировки справок безличные, поэтому работают с любым именем.

## Сохранение картинки

Кнопки «скачать» нет намеренно: в песочнице артефакта загрузки, которые
страница инициирует сама, блокируются. Картинка кладётся в `<img>`, а не
остаётся на `<canvas>`, — по ней работает долгое нажатие и «Сохранить
изображение». На отдельном хостинге ограничения нет, и кнопку можно добавить.
