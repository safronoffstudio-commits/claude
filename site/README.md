# Вацок-генератор

Сайт делает мем в жанре аватарки из нулевых: ковровая рамка, виньетка,
зерно и подпись курсивом с многоточием. Можно поставить своё фото —
оно никуда не уходит, всё рисуется в браузере на `<canvas>`.

Юмор — «про своих»: хинкал, гостеприимство, родня, борьба, свадьбы,
серпантины. 37 подписей по семи темам, плюс поле для своей.

## Как устроено

```
head.part.html    <title>, шрифты, стили страницы
body.part.html    разметка
memes.part.js     37 подписей
script.part.js    отрисовка на canvas + логика
build.mjs         собирает части в две версии
preview.mjs       просмотр в Chromium, кадры в out/
phototest.mjs     проверка загрузки фото
smoke.mjs         проверка собранной страницы
```

`build.mjs` делает два файла из одних исходников:

- `index.art.html` — для публикации артефактом (каркас добавляет паблишер);
- `index.html` — самостоятельная страница для любого статик-хостинга.

```bash
node build.mjs
node preview.mjs
node phototest.mjs путь/к/фото.jpg
node smoke.mjs
```

## Картинка

Квадрат 1080×1080, на выходе JPEG — лёгкая пересжатость тут не баг,
а часть жанра. Слои сверху вниз: фото (или ночной пейзаж с луной,
звёздами и хребтами, если фото нет), цветокор с виньеткой, блики,
затемнение под текстом, подпись, ковровая рамка, зерно.

Рамка рисуется кодом: ступенчатые ромбы с крючками по мотивам
табасаранских ковров. Палитра — марена `#7A2420`, золото `#D4A24C`,
неокрашенная шерсть `#F0E2C6`.

Подпись — Marck Script, изредка Lobster. Рисуется дважды: сначала
с тёмной тенью, потом с тёплым ореолом.

## Грабли, на которые тут уже наступили

`document.fonts.load('80px "Marck Script"')` без второго аргумента грузит
**только латинский сабсет**, и кириллица молча уезжает в засечный фолбэк.
Поэтому в `ensureFonts` всегда передаётся сам текст подписи, а перед
отрисовкой мы дожидаемся именно нужных глифов.

По той же причине `preview.mjs` берёт ссылку на Google Fonts из
`index.art.html`, а не хранит свою копию: разъехавшиеся списки шрифтов
дают превью, которое врёт про живую страницу.

## Сохранение картинки

Кнопки «скачать» нет намеренно: в песочнице артефакта загрузки, которые
страница инициирует сама, блокируются. Картинка кладётся в `<img>`,
поэтому работает долгое нажатие и «Сохранить изображение».
